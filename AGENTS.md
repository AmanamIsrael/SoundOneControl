# AGENTS.md

## Pull requests

PR descriptions contain only these sections:

- **What's Changed** — bulleted summary of the change
- **Notes** — optional; only when something needs flagging (quirks, follow-ups, breaking behavior). Omit entirely if there is nothing to flag.

Never add verification, testing, checklists, or "how to test" sections, and never paste test/lint/build output into a PR description.
